# 手势指南与实机验收

使用 Chrome，授权摄像头。让手离镜头约 40–80 cm，掌心大致面向镜头。需要确认取景时点「查看取景」。

1. **聚灵**。单手张开，在画面中心停约一秒，再左右移动。观察星尘沿掌心流动并保有惯性。换另一只手检查镜像方向。
2. **坍缩与释能**。保持张开片刻，缓慢握拳，停一秒后再张开。分别慢开和快开，比较释放幅度。连续普通张手应始终没有爆发。
3. **拓界**。双掌张开，连续拉近、拉远。星尘空间应随之变化。常规拉伸应不会诞生蝴蝶。
4. **生命诞生**。单手掌心朝向镜头，伸出拇指、食指和中指，收起无名指和小指。保持约半秒，光茧会自动破开，蝴蝶从两指之间飞出。放下手再比一次，可再次触发。
5. **恢复与切换**。在正常和偏弱光线各做一轮。短暂遮挡、交叉、离开再回到镜头时，检查星尘动作是否连贯。关闭摄像头后确认指示灯熄灭，鼠标接管，已有生命继续运动。
6. **本机体验**。比较 Chrome 和 Safari 的摄像头授权、画面和全屏。断开 Wi‑Fi 后重新打开本地页面再做一次生命诞生。监听声音过渡，检查截图中没有界面和预览画面。

测试记录可写浏览器版本、光线、动作完成次数和异常。尤其记录「握拳未蓄能」「放开未释能」「三指姿势无法识别或误触」，这些现象最有助于校准手势阈值。
