# Summer’s Universe · Summer 的宇宙
## V1.0「宇宙初生」

一个在 Mac 本地运行的实时三维数字艺术作品。星尘有惯性，双手能改变空间结构。指尖孕育的蝴蝶醒来后，会独自飞行。

### 在 Mac 上启动

1. 双击 [start.command](start.command)。脚本在本机打开 Chrome，地址为 [127.0.0.1:4173](http://127.0.0.1:4173/)。
2. 点「开启掌中宇宙」，按 Chrome 提示允许摄像头。也可以直接点「先用鼠标探索」。
3. 结束体验时按终端的 Control+C。

需要 Node.js 20.19+ 或 22.12+，推荐 Node.js 22 或 24。首次安装依赖需要联网。本项目已附带本地模型、WASM 和 JS 运行时，安装后可断网启动。终端启动可用 `npm ci`、`npm run dev`，浏览器打开 [127.0.0.1:5173](http://127.0.0.1:5173/)。

### 让宇宙回应你

| 手势 | 鼠标 | 结果 |
| --- | --- | --- |
| 张开手掌，轻轻移动 | 移动 | 星尘向掌心汇聚 |
| 聚拢后握拳，稍停再张开 | 按住约两秒，再松开 | 能量坍缩、积蓄与释放 |
| 两掌张开，拉远或靠近 | 滚轮 | 星尘的真实分布扩张或收缩 |
| 单手伸出拇指、食指和中指，保持约半秒 | 双击 | 光茧孕育、破茧，蝴蝶独立飞行 |

右下角可切换摄像头、调音量、保存纯画面 PNG、进入全屏或重启宇宙。摄像头预览默认隐藏。影像与关键点在本机内存处理，截图仅含三维渲染。浏览器仅保存音量和静音偏好。
